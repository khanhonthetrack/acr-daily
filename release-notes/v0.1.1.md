## ACR Daily 0.1.1

- **Your official time, saved.** While a finished run waits for the game's official time, the timer window says in orange what saves it: go on from the game's results screen. Restarting the stage or quitting the game from there loses the time.
- **A restart from the results screen is told at once.** Start the stage again from the game's results screen and the game keeps no time for the run you finished: the app now says so straight away, instead of minutes later as "the game closed before saving its official result".
- **A finished first run counts even when practice runs arrive first** (a server fix: no update needed for it).
